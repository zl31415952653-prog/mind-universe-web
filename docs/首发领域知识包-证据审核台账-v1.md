# 首发领域知识包：证据审核台账 v1

状态：建设中。此文件不是产品宣传材料，也不是最终默认库内容。  
更新：2026-09-27  
目标：为七空工作流建立第一批可追溯、可人工审核的领域知识。

## 1. 首发规模

本周先建立 **42 个知识核**，而不是仓促堆积大量没有证据边界的内容：

| 领域包 | 首发知识核 | 作用 |
|---|---:|---|
| 学习科学 | 21（每空 3 条） | 第一个完整试验包，验证七空是否能支持一份真实学习资料 |
| 科研与证据方法 | 7（每空 1 条） | 让用户辨认问题、主张、证据、方法与限制 |
| 信息与媒介素养 | 7（每空 1 条） | 让用户判断来源、检索、引用、冲突与信息边界 |
| 数据与数量推理 | 7（每空 1 条） | 让用户理解变量、样本、比较、变异和外推限制 |
| **合计** | **42** | 可完成第一轮人工审核与七空测试 |

通过首轮审核和真实资料测试后，再把后三个领域各扩展到每空 2–3 条；不会为了追求数量而降低证据质量。

## 2. 全文材料的存储与审核规则

```text
本机证据库（不进入 GitHub、不上传 Cloudflare）
├─ papers/      合法取得的 PDF 全文
├─ notes/       每篇文献的人工审核笔记
├─ registry/    引文、DOI、许可、下载日期和条目映射
└─ excerpts/    可合法保留的短摘录与页码定位

线上默认知识库
└─ 用户可读摘要 + 引文 + 合法链接 + 适用边界
```

任何需要通过知网、学校图书馆、出版社订阅获得的论文：由用户通过合法权限下载后提供 PDF；不进入公开 Git 仓库。开放全文或官方免费报告：记录官方下载地址、版本和获取日期。

## 5. 本周验收顺序

1. 已取得的开放全文可支撑七空核心覆盖；补齐 LS-01、LS-02 等馆藏候选后，再逐篇按页码填写审核卡；
2. 审核并定稿“学习科学 × 七空”21 条；
3. 使用一份真实学习材料，由人工按七空工作流标注，记录哪些规则不清；
4. 定稿科研与证据方法、信息与媒介素养、数据与数量推理各 7 条；
5. 将审核通过条目写入正式默认知识库；
6. 再改造 AI 学习分析，让它输出可复核知识单元和七空候选。

## 6. 必须向用户报告的四类问题

1. **证据问题**：没有全文、来源不权威、研究对象不匹配或结论被夸大。
2. **分类问题**：一个知识单元无法以现有规则可靠进入某空，或同时存在多种合理解释。
3. **体验问题**：用户无法理解为什么出现某个候选、无法轻易修改或忽略它。
4. **边界问题**：资料可能涉及隐私、版权、健康/法律/金融高风险建议，或 AI 可能越权判断。

遇到以上问题，系统和开发过程都必须显示依据、影响和备选方案，等待用户决定；不得静默自动处理。
