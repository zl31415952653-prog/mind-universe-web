# 首发领域知识库目录 v1

状态：**建设目录与候选知识核；未经人工审核不得写入线上默认知识库**  
更新：2026-09-27

## 1. 建设原则

先建设“能支撑七空判断的领域知识”，再改造 AI。七空工作流固定；领域知识包持续增加，帮助同一工作流正确理解不同学科里的术语、证据和边界。

首发不追求覆盖全部学科，而是优先建立四个能迁移到几乎所有自学主题的基础领域：

1. 学习科学；
2. 科研与证据方法；
3. 信息与媒介素养；
4. 数据与数量推理。

它们不是四套工作流，而是七空工作流的第一批“判断素材”。后续再加入数学/编程与系统、人文社会论证、健康与医学素养、语言学习等素材包。

## 2. 领域一：学习科学（首个深度试验包）

详细 21 条候选、触发条件、行动与证据目录见：[学习科学-七空工作流与默认知识库-v1.md](./学习科学-七空工作流与默认知识库-v1.md)。

| 空 | 学习科学的知识核 | 典型材料线索 |
|---|---|---|
| 虚空 | 未知类型、前置知识、可探索问题 | “不懂”“术语未定义”“缺少基础” |
| 寂空 | 提取练习、间隔回顾、迁移检验 | 定义、规则、可复述解释 |
| 裂空 | 学习策略比较、困难与反馈、证据冲突 | “更有效”“但/然而”“相反结果” |
| 流空 | 计划—监控—评价—调整 | 步骤、练习、阶段、反馈 |
| 映空 | 把握度、策略复盘、熟悉感错觉 | “我觉得会”“卡住”“哪种方法” |
| 联空 | 前置、例子、类比、应用 | “因为”“例如”“建立联系” |
| 极空 | 研究对象、任务、情境、未定问题 | 限制、样本、条件、未来研究 |

核心证据：Dunlosky 等（2013）、Zimmerman（2002）、Chi & Wylie（2014）、Kapur（2008）、EEF（2025）、National Academies（2018）。

## 3. 领域二：科研与证据方法

这个领域帮助用户区分“一个结论”“支撑结论的证据”“研究如何得到证据”“结论在哪些条件下不成立”。它是虚空、裂空、联空和极空的重要判断素材。

| 空 | 候选默认知识核 | 用户可执行动作 |
|---|---|---|
| 虚空 | 研究问题要区分对象、现象、关系与条件 | 将模糊问题改写为“对谁、什么条件、观察什么” |
| 寂空 | 主张、证据、推理三者不能互相替代 | 用一句话分别写出主张与支持它的证据 |
| 裂空 | 不同研究结论先比较设计、样本、测量和情境 | 做一张“结论—证据—条件”对照表 |
| 流空 | 探究是提出问题、查找、比较、解释、修订的循环 | 为当前材料标记所在研究步骤 |
| 映空 | 相信某个结论前，先区分熟悉、认同与证据充分 | 写下“我相信它的理由是什么” |
| 联空 | 一条证据必须能连回来源、方法与主张 | 建立“主张 ← 证据 ← 来源”的关系链 |
| 极空 | 相关不等于因果；样本不等于所有人 | 写下不能从研究推出的结论 |

首批权威素材入口：

- National Academies, *How People Learn II*（2018），官方免费 PDF，DOI: [10.17226/24783](https://doi.org/10.17226/24783)。
- ACRL, *Framework for Information Literacy for Higher Education*（2016），官方框架与中文译本入口：[官方页面](https://www.ala.org/acrl/standards/ilframework)。
- 用户后续应补充：适合中国公众的研究方法教材/公开课程及通过学校图书馆合法取得的同行评审论文。

## 4. 领域三：信息与媒介素养

这个领域不把“资料多”误当成“资料可靠”。它为用户导入网页、论文、课程和 AI 内容时提供来源、检索、引用、权威与伦理的判断素材。

| 空 | 候选默认知识核 | 用户可执行动作 |
|---|---|---|
| 虚空 | 信息需求要先说明目的、范围和需要的证据类型 | 写下“我要用它回答什么问题” |
| 寂空 | 来源、作者、日期、版本和原始出处是可核验信息 | 保存稳定链接、作者和发表日期 |
| 裂空 | 面对冲突信息先追到原始来源，再比较证据与语境 | 至少核对两条独立来源 |
| 流空 | 检索是不断改写关键词、筛选与追踪引用的过程 | 记录使用过的关键词和为何排除某来源 |
| 映空 | 认可某观点不等于它可靠 | 分开记录“我倾向相信”与“可验证依据” |
| 联空 | 资料应连接到它支持的具体主张，而非只收藏链接 | 每条来源标记它支持/反驳什么 |
| 极空 | 权威具有情境；资料制作过程和利益关系会影响可用性 | 写下来源不适合回答什么问题 |

首批权威素材入口：

- ACRL 信息素养框架（2016），覆盖“研究是探究”“检索是策略性探索”“权威具情境性”等内容。[官方页面](https://www.ala.org/acrl/standards/ilframework)
- 后续补充：新闻素养、中文互联网信息质量与 AI 生成内容核验的中国本土研究；必须先审核来源与研究方法。

## 5. 领域四：数据与数量推理

这个领域让用户在遇到百分比、图表、研究结果、推荐数据或 AI 数字结论时，能先问数据从哪里来、代表谁、波动有多大、结论是否越界。

| 空 | 候选默认知识核 | 用户可执行动作 |
|---|---|---|
| 虚空 | 先说清变量、对象、时间范围和要回答的问题 | 将“数据说明什么”改写为具体统计问题 |
| 寂空 | 描述性数字、比较和推断的含义不同 | 用自己的话说明一个图表实际表达什么 |
| 裂空 | 两组数据不同，不等于原因已经确定 | 检查比较条件、遗漏变量与测量差异 |
| 流空 | 数据探究包括提问、收集、分析、解释与沟通 | 标记当前材料处于哪个步骤 |
| 映空 | 图表直觉可能被坐标、比例、样本和叙述误导 | 重新查看坐标轴、样本量和缺失值 |
| 联空 | 数据结论必须连接到数据来源、测量方式和问题 | 建立“问题—数据—分析—结论”链 |
| 极空 | 样本、误差、变异与缺失限制结论外推 | 写下结论适用的人群与不确定处 |

首批权威素材入口：

- American Statistical Association, *GAISE II*，覆盖统计问题、数据、变异、结论与沟通。[官方报告页](https://www.amstat.org/education/guidelines-for-assessment-and-instruction-in-statistics-education-%28gaise%29-reports)
- 官方可读版本：[GAISE II PDF](https://ies.ed.gov/sites/default/files/ies/document/2024/10/GAISEIIPreK-12_Full.pdf)。
- 后续补充：中国统计素养、数据新闻与中国公开数据使用场景的可审核材料。

## 6. 每个领域知识核进入默认库的审核标准

1. 必须能说清它服务的是哪一个七空工作流，而非仅有一个漂亮标题。
2. 必须同时包含：领域、概念、何时触发、用户动作、来源、边界。
3. 来源优先级：系统综述/共识报告 > 元分析 > 同行评审研究 > 权威学会或公共机构指南 > 经审核的教材。
4. 不能因为“看起来有用”就进入默认库；研究结论必须与研究对象、情境和限制一起入库。
5. 所有论文全文要记录合法下载来源；受版权保护的全文只保存于本机非 Git 证据目录，绝不推送到公开仓库或部署网站。

## 7. 建设顺序

1. 审核“学习科学 × 七空”的 21 条候选，取得原始论文全文或官方全文材料；
2. 将通过的学习科学条目写入正式默认库；
3. 完成科研与证据方法、信息与媒介素养、数据与数量推理各 7 条核心知识；
4. 用这四个领域的真实材料做人工标注，检验七空工作流；
5. 再实现 AI 的“知识单元提取 → 七空候选 → 人工确认 → 任务与关系”流程；
6. 依据真实使用与审核结果扩展数学/编程、人文社会、健康医学、语言学习等领域。
