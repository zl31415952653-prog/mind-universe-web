# 心智宇宙 · INFINITY V2

一个本地优先的个人认知地图：经历是星尘，资料是知识晶体，关系与迁移由用户亲自确认。

第一次维护项目，先看 [项目文件夹说明与分享指南](项目文件夹说明.md)。源码仓库是代码备份与协作入口，不等于线上网站已更新；本机笔记、密钥和论文全文不随源码上传。

## 本地运行

```powershell
npm install
npm run dev
```

访问 `http://localhost:5173`；同一局域网可使用终端显示的 `Network` 地址。生产构建：

```powershell
npm run build
```

## AI 的三种模式

- **本地引导**：无需联网或 Key，仍能把对话整理为用户可编辑的候选草案。
- **托管 AI**：适用于 Cloudflare Pages 部署；浏览器请求同站 `/api/chat/completions`，Key 不离开服务端。
- **个人 Key**：高级用户临时填写任意 OpenAI 兼容接口和 Key；Key 只保留在当前页面会话。

无论模式如何，AI 都不能自动写入记录；用户编辑并确认后才会成为星尘。

## 学习资料导入与核对

在“学习 → 资料导入”选择 PDF 后，先查看总页数，再选择并提取本次要学的页段。页码按 PDF 文件页序计数，支持选择文档后部页面；每次最多提取 40 页。正文可以继续删选，界面会显示本地可拆分的句段数量。当前本地规则一次最多处理 30 个句段，超过时先缩小范围。

生成后进入学习地图逐条核对。候选保留材料来源、原文摘录及 PDF 页定位；可以改写、暂缓、忽略或恢复核对，确认后才进入知识库。本地模式只按句段和有限中英文词面线索给建议。

托管 AI 与个人 Key 模式使用同一套七空工作流提示，要求从正文提取最多 12 个知识单元，每个单元逐项返回七空候选、依据不足或需补充。每次正文最多 12000 字符，不静默截断。只有用户点击生成才发送材料标题、出处与所选正文，不附带其他笔记。前端核对原文摘录、字符位置及候选线索；引用不能定位、七空状态不完整或响应截断时整批拒绝，不拿材料开头填充 AI 结果。PDF 页码由本机文本标记计算，不信任模型生成的页码。

原文引用匹配不代表摘要、分类或建议正确；仍须人工审核。AI 下一步仅显示为建议，不自动创建任务或关系。2026-10-04 已获授权用两段原创合成短材料进行个人 Key 真实试跑，观察到成功输出以及截断/格式失败，详见 [试跑记录](docs/AI学习真实试跑记录-2026-10-04.md)。这不代表长材料、实际学习效果或线上托管服务已验收。

导入时可选“不使用领域包”（默认）或“学习科学 · 21 条暂行素材”。这是对现有暂行包的中英文词面检索，不是语义搜索、外部数据库检索或论文全文分析。每个候选按原文最多推荐 3 条参考，显示匹配词、来源、登记定位、适用限制和可选动作；无匹配则不推荐。参考不影响本地主空，不自动导入个人知识库或建立关系。登记页码来自现有素材包，本轮未重新核页。AI 模式选包后，最多 6 条公开摘要、来源与限制会同正文发送至所选模型，以启发学习动作；系统要求其不能代替材料原文依据，但这一约束的实际模型表现仍需人工验收。

## Cloudflare Pages + D1 部署（推荐）

2026-10-12 当前方向：普通体验免登录，云端能力采用邀请制用户名＋密码，不需要 Authing 邮箱验证。本地已实现，线上尚未切换；新增迁移、恢复码、邀请码发放及运行资源门槛见 [邀请制内测与部署说明](docs/邀请制账号内测-实现与部署-2026-10-12.md)。**不能仅关闭 Authing 开关或只部署前端就视为完成。** [旧 Authing 接入清单](docs/Authing接入与控制台配置-2026-10-07.md)仅用于历史核查和回退。

1. 将此目录推送到 GitHub，创建 Cloudflare Pages 项目并连接仓库。
2. 创建一个 D1 数据库，将 [wrangler.example.toml](./wrangler.example.toml) 复制为本地 `wrangler.toml` 后填入数据库 ID。全新库依序执行 `migrations/0001`–`0004`；已有库先核对迁移状态，只补缺失的增量，不能盲目重跑或清库。
3. 在 Pages 项目中将 D1 绑定命名为 `DB`，设置构建命令为 `npm run build`，输出目录为 `dist`。
4. 在项目的 **Settings → Variables and Secrets** 为 Production 和 Preview 设置：
   - `DEEPSEEK_API_KEY`：DeepSeek 的服务端 Key（机密变量）；
   - `AI_BASE_URL`：`https://api.deepseek.com`；
   - `AI_MODEL`：`deepseek-flash`。
5. 新内测须额外配置 `AUTH_PROVIDER=invite` 并通过运行资源与隔离预览验收；未配置时关闭公开注册。进入“云端内测”凭邀请创建账号，登录后主动保存/恢复快照。托管 AI 仍受账号额度限制。

`functions/api/chat/completions.js` 是 Cloudflare Pages Function：它会固定系统边界、限制输入长度，并从环境变量取得 Key。请勿把真实 Key 写进前端代码、`.dev.vars` 或 Git 仓库。

Cloudflare Pages 根据 `functions/` 的文件路径生成接口路由，环境变量可在 Pages 控制台作为密钥配置。[官方路由文档](https://developers.cloudflare.com/pages/functions/routing/) [官方变量文档](https://developers.cloudflare.com/pages/functions/bindings/)

当前本地版本包含邀请制用户名密码、HttpOnly 会话、一次性恢复码、账号请求限流、有限 AI 额度、受控 AI 代理和手动云快照。它仍是待线上验收的受控内测方案，不是开放注册系统；公开推广前需补充独立安全审查、边缘防滥用、监控告警和隐私合规评估。邮件验证不再是本轮内测前置条件。

## 本地与云端的边界

- 不登录时：经历、笔记、学习资料与图谱只保留在本机 IndexedDB，可导出 JSON。
- 登录后：也不会自动上传；只有在“隐私 → 账户”点击“保存到云端”时才会上传一份快照。
- 托管 AI：只在用户主动发起对话、资料分析、关系发现或回望时调用；结果均需用户确认。
- 个人 Key：仅存在当前页面会话，绝不进入备份、IndexedDB 或云端快照。

## 发布前检查

本轮选定文件、资料排除项及生产验收顺序见 [2026-10-04 发布清单](docs/本轮发布验收清单-2026-10-04.md)。本地候选确认现可选择不添加任务、三项基础练习或编辑下一步后添加一项任务；默认不自动生成任务。操作验收见 [任务闭环记录](docs/学习任务可选闭环-2026-10-04.md)。

1. `npm run build` 必须通过。
2. 核对目标 D1 的 `0001`–`0004` 迁移与 `DB` 绑定；已有库只补缺失增量，先在隔离预览验证，不清库或盲目重跑。
3. 只把 `DEEPSEEK_API_KEY` 放入云端密钥，不写入 Git、前端变量或 `wrangler.toml`。
4. 在隔离预览验证邀请创建账号、登录、刷新会话、退出、恢复码一次性使用、双账号隔离、手动上传和恢复，并实测密码计算的运行资源；恢复会覆盖当前设备数据，先导出备份。
5. 对托管 AI 设置额度与频率限制后，再开放外部用户。
