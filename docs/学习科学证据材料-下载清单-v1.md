# 学习科学证据材料：下载清单 v1

更新：2026-09-27  
用途：为“学习科学 × 七空”首批 21 条候选知识建立真实、可核验的全文证据。  
原则：只保留官方开放全文、作者合法公开版本，或用户通过湖南师大图书馆合法下载的个人学习/科研副本。

## 0. 湖南师大图书馆的统一入口

1. 打开 [湖南师范大学图书馆](http://lib.hunnu.edu.cn)。
2. 选择“资源”→“数字资源”，搜索数据库名称。
3. 校外访问按图书馆的统一认证/微信绑定说明完成身份认证；不要把账号或密码发给任何人。
4. 先在图书馆资源导航内搜索 **Taylor & Francis**、**EBSCOhost**、**Web of Science**、**CNKI**、**万方**。Web of Science 主要用于检索与引文追踪，不一定提供 PDF；全文通常回到出版社或图书馆链接获取。

官方访问说明：[湖南师范大学图书馆数字资源访问说明](https://io.hunnu.edu.cn/info/1036/2311.htm)。说明中明确电子文献限个人学习、科研和教学使用。

## D. 下载后如何交给项目

请将 PDF 直接发到对话中即可。不要改动正文，也不要将文件上传到公开 GitHub 仓库。

收到后将执行：

1. 检查题名、作者、年份、DOI 与下载来源是否匹配；
2. 提取文本并记录可引用页码；
3. 为每篇论文填写审核卡：支持什么、不支持什么、研究对象、适用条件；
4. 映射到学习科学的七空候选知识；
5. 把通过审核的中文知识条目交给用户确认后，再写入默认知识库。
