# 心智宇宙 INFINITY

一个个人认知外化系统：以情感、知识、日常三类经历为原料，通过"七空"、中式色卡、情感与感官编码，建立可检索、可关联、可视化的个人认知宇宙。**核心是编码，记录服务于编码。**

> **开发状态**：按《心智宇宙-现状分析与改善计划-2026-09-13.md》分 9 轮推进，已完成第 0–7 轮（工程加固/离线优先/经历模块/编码/知识库/关系图谱/3D 宇宙/AI 受控接入）。剩余第 8 轮生产化见下文"尚缺功能"。

## 当前已实现

- 账户注册、登录（bcrypt + JWT）与按用户的数据隔离；登录/注册限流（同 IP 15 分钟 10 次）
- **离线优先**：数据先写入浏览器 IndexedDB（Dexie），立即可见，后台同步队列推送服务器；断网可新建/编辑/删除/搜索，恢复网络自动同步；并发编辑冲突不静默覆盖（标记后由用户裁决"保留本地版/采用云端版"）
- **PWA**：可安装到桌面/手机主屏；应用壳离线可用（生产构建生效，开发模式不启用）
- **双链笔记**：正文写 `[[标题]]` 即建立双向链接——预览中可点击跳转，编辑页显示"反向链接"面板（哪些条目链到了本条）
- **Markdown**：正文实时渲染预览（GFM 表格/任务列表等），列表卡片自动去 Markdown 符号
- **三类型模板**：情感/知识/日常各有一套默认模板，新建时切换类型自动套用（可手动"插入模板"）
- **附件**：图片/音频上传（单个 ≤10MB，鉴权下载），附件引用随条目保存
- **历史版本**：每次保存同步后生成历史快照，可在编辑页回看并载入旧版本
- SQLite（WAL）持久化、软删除、审计日志、JSON 导出、编辑版本冲突检测（409）
- 情感/知识/日常三种经历（创建时强制选择），主空（必填）+ 附加空（可选）；情感编码（效价/强度/标签）与基础色块编码（6 色过渡色卡）
- 预置 5 条默认知识条目（七空指南、编码规则、情感词汇、学习科学、色卡说明），并打包进前端离线兜底
- **3D 宇宙**（Three.js + R3F）：七银河系可拖拽/聚焦，星尘悬停卡片/点击进入，八类关系连线，虫洞/超新星，新星尘动画，宇宙膨胀，沉浸模式
- **关系图谱**（Cytoscape 力导向）：类型线型区分、筛选、图例、AI 候选边（金色虚线、接受/拒绝）
- **AI 受控接入**：OpenAI 兼容模型适配器（密钥仅服务器环境变量）+ ai_runs 回溯；编码建议逐项确认工作流；AI 关系发现；AI 学习页（目标/分块计划/进度/认知负荷）；未配置模型时全部降级本地启发式
- 仪表盘（七空分布图 + 情感热力图）、时间线（发生时间 + 日周月年缩放）、"允许 AI 分析"开关（默认关闭）
- 前端 + 后端均为 TypeScript；`npm run smoke` 冒烟测试（39 项断言）

## 本地启动（开发用）

1. 安装 **Node.js 22.5 或更高版本**（`node:sqlite` 的最低要求；README 初版写的 Node 20 有误）。
2. 在本目录执行 `npm install`。
3. 复制 `.env.example` 为 `.env`，修改 `JWT_SECRET` 为随机长字符串（开发环境不设置会用临时默认值并告警；生产环境不设置将拒绝启动）。
4. 执行 `npm run dev`，本机打开 **http://localhost:5173**。

开发模式下前端为 5173 端口、API 为 8787 端口，Vite 已将 `/api` 代理到 API 服务（同源访问，无需放宽 CORS）。

> **部署**：由阿里云服务器上的"小龙虾"执行，本地无需配置局域网访问。部署者注意：服务器需 Node.js ≥ 22.5；数据库与附件目录可用 `DATA_DIR` 环境变量指定（如 `/opt/infinity/data`）；生产构建产物为 `dist/`（前端）+ `dist-server/`（后端），`npm start` 启动后端。

## 生产构建与运行

```powershell
npm run build   # 含 tsc 类型检查 + Vite 构建
npm start       # 启动 API（仅本机 8787）
```

生产环境用 Nginx 托管 `dist/`，并将 `/api` 反向代理至 `127.0.0.1:8787`，全程 HTTPS。部署细则、备份与安全验收见《心智宇宙-实施与阿里云部署方案书.md》。
