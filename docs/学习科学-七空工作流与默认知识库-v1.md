适用对象：普通自我学习者。不是诊断工具、能力测评或自动分类器。

> 2026-10-03 实现补记（不覆盖历史建设方案）：21 条素材已获准暂行导入，证据复核长期维护。AI 接口已改为最多 12 个知识单元、逐单元七空状态及原文校验，模拟响应测试和构建通过，尚无真实模型质量验收。可选学习科学包词面参考检索已接入：不更改本地主空，原文和参考分开显示，不等于语义证据检索或全文复核。下文第 7、8 节是较早版本的门槛与差距，不代表当前全部状态，以 AGENTS.md 和本补记为准。

## 1. 这份文件解决什么问题

一个学习领域不是“属于某一空”。同一份学习材料可同时包含未知、稳定定义、冲突、过程、反思、连接与边界。

本项目只有 **七个全局、稳定的七空工作流**。学习领域不是工作流的横轴，也不会各自长出另一套工作流；它们是不断扩展的**领域素材包**，为同一套七空工作流提供术语、证据、典型问题、判断规则和行动示例。

```text
七空通用工作流（固定的七条）
        ↑
领域素材包（学习科学 / 信息素养 / 数据推理 / ……，持续扩展）
        ↑
用户导入的学习材料与个人目标
```

例如，“虚空”在任何领域都执行同一件事：识别未知 → 说清未知对象 → 形成可探索问题 → 找到下一步。学习科学素材包会补充“策略、前置知识、练习”这些术语；数据推理素材包会补充“变量、样本、测量、变异”这些术语，但不会产生一个新的“数据虚空工作流”。

本文件先以“学习科学”作为第一份领域素材包和验证样本。后续信息素养、研究方法、数据推理等领域只补充素材包，不改写七条通用工作流。

## 2. AI 学习功能的目标流程

```text
用户创建学习项目并选择学习领域
→ 导入一份文字、网页说明或 PDF
→ 提取材料中的知识单元（概念、主张、方法、例子、证据、限制）
→ 调用相应领域素材包，识别术语与证据线索
→ 对每个知识单元逐一运行同一套七空工作流
→ 每一空输出「有候选 / 无充分依据 / 需要用户补充」
→ 用户审核、修改、忽略或确认
→ 已确认单元进入知识库、学习任务与知识关系图
```

**不能做的事**：将整份材料强行归为某一空；因某空没有材料线索而编造内容；未经用户确认写入知识库或关系图。

## 3. 七个通用工作流（不随领域改变）

| 空 | 固定输入 | 固定处理 | 固定输出 | 典型路由 |
|---|---|---|---|---|
| 虚空 | 陌生、缺失、未解释、用户提问 | 识别未知对象与未知类型，形成可探索问题 | 问题、前置缺口、下一步检索/学习动作 | 找到过程进入流空；发现冲突进入裂空 |
| 寂空 | 定义、规则、已形成解释 | 通过回忆、例子、应用检查理解 | 可检验表述、回顾任务、应用动作 | 检验失败回虚空/流空；发现边界进极空 |
| 裂空 | 相反主张、易混定义、证据不一致 | 比较双方、证据、条件与术语 | 冲突说明、待查证点、对比任务 | 证据不足进极空；形成关系进联空 |
| 流空 | 步骤、练习、形成中的理解 | 将目标拆成可反馈的下一步 | 任务、反馈点、进度记录 | 反思策略进映空；稳定理解进寂空 |
| 映空 | 把握度、学习感受、策略选择 | 比较自我判断与可观察证据 | 校准问题、策略复盘、可检验动作 | 未知类型不明进虚空；调整计划进流空 |
| 联空 | 前置、对比、类比、因果、应用线索 | 要求说明关系类型、两端和依据 | 等待确认的关系候选 | 关系有争议进裂空；适用范围进极空 |
| 极空 | 限制、样本、情境、开放问题 | 区分已知、未知和不能推出的结论 | 边界说明、待验证问题 | 产生新问题进虚空；补证据进裂空 |

**通用硬规则**：任何工作流都允许输出“无充分依据”或“需用户补充”；没有材料依据时不生成内容。知识单元可以在时间中迁移，不能被永久固定在某一空。

## 4. 每个知识单元的统一数据规范

| 字段 | 规则 |
|---|---|
| 所属领域 | 首发为“学习科学”，后续可扩展 |
| 知识类型 | 概念、主张、方法、例子、证据、限制、问题 |
| 原文依据 | 材料中的页码/段落/摘录；没有则不生成候选 |
| 主空 | 当前最适合处理它的工作流；仅为候选 |
| 附属空 | 0–2 个；只在材料有明确依据时出现 |
| 七空状态 | `有候选` / `无充分依据` / `需用户补充`，而非七选一强制分类 |
| 下一步 | 一项可执行学习动作 |
| 证据链 | 资料来源、外部研究来源、适用范围 |
| 审核状态 | 待用户确认 / 已确认 / 忽略 / 需查证 |

## 5. 学习科学试验素材包：七个通用工作流的第一轮验证

以下不是“学习科学独有的七套工作流”，而是学习科学中的概念、研究证据和行动示例，用来检验上面的七个通用工作流是否足够清楚。

### ∅₁ 虚空：把未知变成可探索的问题

**触发条件**：材料出现陌生术语、缺失前置概念、未解释的机制，或用户明确说“不懂”。  
**输出**：未知类型、需要补齐的前置概念、一个可以检索或向资料追问的问题。  
**不输出**：对用户能力的判断。

候选默认知识：

1. **先辨认缺口类型：定义、机制、方法、证据还是应用？**  
   行动：把“我不会”改写成具体问题。  
   证据锚点：Loewenstein（1994）；National Academies（2018）。
2. **先找前置概念，再硬读新内容。**  
   行动：列出理解当前主题必须先弄清的 1–3 个概念。  
   证据锚点：National Academies（2018）。
3. **未知需要一个可检索的问题。**  
   行动：写出“什么是… / 为什么… / 在什么条件下…”中的一个问题。  
   证据锚点：ACRL（2016）。

### ∅₂ 寂空：检验暂时稳定的理解

**触发条件**：材料提供明确概念、规则、程序或用户已经能解释的知识。  
**输出**：可回忆定义、可应用例子、一次延迟回顾任务。  
**不输出**：“已永久掌握”的结论。

候选默认知识：

4. **熟悉不等于理解：先合上资料再回忆。**  
   行动：不用原文，解释一个概念或回答一个问题。  
   证据锚点：Dunlosky 等（2013）。
5. **把回顾分散到时间中。**  
   行动：在不同日期回忆并补正，而非连续重读。  
   证据锚点：Dunlosky 等（2013）。
6. **能在新例子中使用，才算经受了一次检验。**  
   行动：给概念另找一个例子或完成小型应用。  
   证据锚点：National Academies（2018）。

### ∅₃ 裂空：明确冲突与易混淆之处

**触发条件**：材料内出现相反主张、定义相似但条件不同，或用户的理解与证据不一致。  
**输出**：冲突双方、各自证据、适用条件和需要查证的问题。  
**不输出**：AI 自动判定“哪方正确”。

候选默认知识：

7. **把相似策略分开比较，而不是只问哪一个更好。**  
   行动：比较目标、材料、练习方式与测验间隔。  
   证据锚点：Dunlosky 等（2013）。
8. **困难不自动带来学习收益。**  
   行动：检查挑战后是否有反馈、讲解或整合。  
   证据锚点：Kapur（2008）。
9. **主张应与证据强度和研究情境一起阅读。**  
   行动：写下研究对象、任务情境与仍不确定之处。  
   证据锚点：EEF（2025）；National Academies（2018）。

### ∅₄ 流空：让学习过程有下一步

**触发条件**：材料描述步骤、练习、形成中的理解或用户正在推进一个项目。  
**输出**：小任务、反馈点、回顾时间和可调整的下一步。  
**不输出**：以连续打卡代替学习质量。

候选默认知识：

10. **学习是计划、监控、评价、调整的循环。**  
    行动：为本轮学习写一个可检验目标。  
    证据锚点：Zimmerman（2002）；EEF（2025）。
11. **把大目标拆成能得到反馈的小步骤。**  
    行动：完成一次解释、练习或对照，不只收藏资料。  
    证据锚点：EEF（2025）。
12. **下一步由证据决定，不由焦虑决定。**  
    行动：根据回忆卡住处安排复习或补前置。  
    证据锚点：Dunlosky 等（2013）；EEF（2025）。

### ∅₅ 映空：校准对自己理解的判断

**触发条件**：用户表达把握度、困难、策略选择或学习体验。  
**输出**：自我判断、可检验方式、策略复盘问题。  
**不输出**：人格、智力、心理状态诊断。

候选默认知识：

13. **记录把握度，再用一次回忆或应用校验它。**  
    行动：先写“我有多确定”，再测试而非凭感觉决定。  
    证据锚点：Zimmerman（2002）；EEF（2025）。
14. **复盘的是策略与证据，不是给自己打标签。**  
    行动：记录哪种方法、在哪类任务中帮助了理解。  
    证据锚点：EEF（2025）。
15. **停滞时先区分：不知道、不会做、无法迁移，还是证据不足。**  
    行动：把问题转回虚空、流空、裂空或极空。  
    证据锚点：本项目工作流规则；需后续用户研究验证。

### ∅₆ 联空：让关系可说明、可复核

**触发条件**：材料呈现前置关系、对比、类比、因果或应用例子。  
**输出**：关系类型、两端知识单元、原文依据、用户确认入口。  
**不输出**：只因关键词相同而建立关系。

候选默认知识：

16. **解释、比较和举例会把知识从接收变为建构。**  
    行动：把一个概念与一个例子或旧知识连起来，并说明理由。  
    证据锚点：Chi 与 Wylie（2014）。
17. **每条关系都要注明“为什么成立”。**  
    行动：选择前置、对比、类比、应用或冲突，并写下一句理由。  
    证据锚点：本项目关系审核规则；需后续用户研究验证。
18. **跨领域连接是候选，不是事实。**  
    行动：保留材料出处，等待用户确认或忽略。  
    证据锚点：Chi 与 Wylie（2014）；本项目人工审核原则。

### ∅₇ 极空：记录边界、限制和待验证问题

**触发条件**：材料出现研究限制、样本范围、条件限制、开放问题或不确定结论。  
**输出**：适用范围、不能推出的结论、待验证问题。  
**不输出**：将没有结论误写成负面结果。

候选默认知识：

19. **研究结果不能脱离对象、任务和情境。**  
    行动：记录“这项结论研究了谁、在什么任务中成立”。  
    证据锚点：National Academies（2018）；EEF（2025）。
20. **“尚不确定”是可保存的知识。**  
    行动：把证据不足、定义未定或尚待检验的问题保留下来。  
    证据锚点：ACRL（2016）。
21. **产品提示不等于对个人效果的保证。**  
    行动：将研究结论与自己的实际练习结果分开记录。  
    证据锚点：本项目产品边界；需后续用户研究验证。

## 7. 进入产品前的审核门槛

1. 每条默认知识至少有一个 E01–E08 证据锚点，或明确标为“产品规则，待用户研究验证”。
2. 每条必须写明适用条件和不可作出的承诺。
3. 原始论文全文只放入本机的非 Git 证据目录；默认知识库和线上页面只展示用户可读摘要、引文和合法链接。
4. 用户审核通过后，才将 21 条候选写入 `src/defaultKnowledge.ts` 并进入部署。
5. AI 改造开始前，先由人工用至少 3 份真实学习材料测试这七个工作流是否产生可理解、可修改的候选。

## 8. 当前实现差距

当前 AI 学习功能仅输出：一张摘要卡、关键词、前置知识、一个主空、最多两个附属空和理由。它还没有：

- 把一份材料拆成多个知识单元；
- 对每个单元并行检查七个工作流；
- 返回“无充分依据”与“需用户补充”；
- 保存原文依据、证据锚点与审核状态；
- 让用户逐个确认关系与学习任务。

这些是后续 AI 功能改造的明确实施清单；本文件和人工审核后的 21 条默认知识将成为其规则依据。
