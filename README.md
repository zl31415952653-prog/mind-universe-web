# 心智宇宙 INFINITY

一个离线优先的个人认知外化系统：用七空、情感、色卡、双链和关系图谱组织情感经历、知识经历与日常经历。

## 本地启动（含局域网访问）

1. 安装 Node.js 20 LTS 或更高版本。
2. 在本目录执行 `npm install`。
3. 复制 `.env.example` 为 `.env`，至少修改 `JWT_SECRET`。
4. 执行 `npm run dev`。
5. 本机打开 `http://localhost:5173`。局域网设备打开 `http://你的电脑局域网IP:5173`；Windows 防火墙如提示，请允许专用网络访问。

开发模式下前端为 5173 端口、API 为 8787 端口。Vite 已监听 `0.0.0.0`，因此可被局域网访问。

## 生产构建与运行

```powershell
npm run build
npm start
```

生产环境用 Nginx 托管 `dist/`，并将 `/api` 反向代理至 `127.0.0.1:8787`。详细要求见 `心智宇宙-实施与阿里云部署方案书.md`。

## 当前实现范围

- 账户注册、登录与用户数据隔离
- SQLite（WAL）持久化、软删除、审计记录、JSON 导出
- 情感/知识/日常三种经历，主空与附空、情感和色块编码
- 默认离线知识库、Markdown 正文、标签、搜索、时间线
- 2D 宇宙数据可视化、图谱入口、AI 可见开关与本地启发式编码建议

AI 建议必须由用户确认；默认不会把条目交给 AI。附件上传、真实模型适配器、数据库迁移脚本、服务端同步队列和 Three.js 高性能渲染属于下一轮增强项，部署真实用户数据前必须按方案书完成安全与备份验收。
